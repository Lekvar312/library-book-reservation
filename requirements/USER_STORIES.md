# User Stories

1. **Як користувач**, я хочу переглядати каталог книг, щоб знаходити потрібні мені книги.

2. **Як користувач**, я хочу шукати та фільтрувати книги за назвою, автором або жанром, щоб швидше знаходити потрібне видання.

3. **Як користувач**, я хочу резервувати доступну книгу, щоб мати можливість отримати її в бібліотеці.

4. **Як бібліотекар**, я хочу переглядати та обробляти резервування користувачів, щоб контролювати видачу книг.

5. **Як адміністратор**, я хочу керувати користувачами та їхніми ролями, щоб контролювати доступ до функцій системи.
