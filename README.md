# Library Book Reservation System

Вебсистема для резервування книг користувачами бібліотеки. Система дозволяє переглядати доступні книги, здійснювати їх резервування та керувати власними бронюваннями.

## Потенційні ролі

- **Користувач** — перегляд і пошук книг, резервування та скасування власних бронювань.
- **Бібліотекар** — керування книгами та обробка резервувань користувачів.
- **Адміністратор** — керування користувачами, ролями та системою.
