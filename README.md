# Library Book Reservation System

Вебсистема для резервування книг користувачами бібліотеки. Метою системи є спрощення процесу пошуку та резервування книг, а також автоматизація основних операцій, пов’язаних з обліком книг і бронюваннями.

Користувачі можуть переглядати каталог доступних книг, знаходити необхідні видання за назвою, автором або іншими параметрами, переглядати інформацію про книгу та створювати або скасовувати власні резервування.

Система також передбачає можливість для працівників бібліотеки керувати каталогом книг, переглядати активні резервування та контролювати їх статус.

## Потенційні ролі

### Користувач

- Перегляд каталогу книг.
- Пошук та фільтрація книг.
- Перегляд детальної інформації про книгу.
- Створення резервування.
- Перегляд власних резервувань.
- Скасування резервування.

### Бібліотекар

- Додавання, редагування та видалення книг.
- Перегляд списку резервувань.
- Підтвердження або скасування резервувань.
- Оновлення статусу доступності книг.
- Перегляд інформації про користувачів.

### Адміністратор

- Керування користувачами системи.
- Керування ролями та правами доступу.
- Керування каталогом книг.
- Перегляд та контроль усіх резервувань.
- Налаштування основних параметрів системи.
